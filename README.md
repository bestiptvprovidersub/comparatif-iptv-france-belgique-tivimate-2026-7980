## ⚡ Conseils techniques pour éliminer les saccades
1. Utilisez **TiviMate Premium** avec une mémoire tampon réglée sur *Moyenne* (2000 ms).
2. Configurez les DNS de votre box vers Cloudflare (`1.1.1.1`) ou Google (`8.8.8.8`).
3. Privilégiez une connexion filaire Ethernet plutôt que le Wi-Fi 2.4 GHz.
